## 🧠 Sobre o projeto
Este é o meu **portfólio pessoal**, desenvolvido para apresentar minhas habilidades como Analista de Sistemas e Desenvolvedor, além de projetos e formas de contato.

O site foi construído utilizando tecnologias puras da web (sem frameworks), com foco em **design minimalista**, **tema moderno**, **responsividade** e **animações suaves**.

---

## 🛠️ Tecnologias utilizadas
- **HTML5**
- **CSS3**
- **JavaScript**
- **Font Awesome (ícones)**
- **Web3Forms** (para envio de mensagens via AJAX sem backend)
- **Vercel** (para deploy e hospedagem gratuita)
